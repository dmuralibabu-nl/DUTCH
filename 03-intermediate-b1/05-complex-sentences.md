# 🔗 Complex Sentences

## Conjunctions (Voegwoorden)

### Coordinating Conjunctions (No word order change)
These connect two main clauses — word order stays normal:

| Dutch | English | Example |
|-------|---------|---------|
| en | and | Ik werk **en** hij studeert. |
| maar | but | Ik wil komen, **maar** ik heb geen tijd. |
| of | or | Wil je koffie **of** thee? |
| want | because | Ik blijf thuis, **want** het regent. |
| dus | so/therefore | Het regent, **dus** ik neem een paraplu. |

### Subordinating Conjunctions (Verb goes to END!) ⚠️
These create subordinate clauses — the verb moves to the END:

| Dutch | English | Example |
|-------|---------|---------|
| dat | that | Ik denk **dat** hij ziek **is**. |
| omdat | because | Ik blijf thuis **omdat** het **regent**. |
| als | if/when | **Als** het mooi weer **is**, ga ik fietsen. |
| wanneer | when | **Wanneer** hij **komt**, gaan we eten. |
| terwijl | while | Ik lees **terwijl** hij **kookt**. |
| hoewel/al | although | **Hoewel** het **regent**, ga ik fietsen. |
| voordat | before | **Voordat** ik **vertrek**, bel ik je. |
| nadat | after | **Nadat** hij **had** gegeten, ging hij slapen. |
| totdat | until | Wacht **totdat** ik **kom**. |
| sinds | since | **Sinds** ik hier **woon**, ben ik gelukkig. |
| zodat | so that | Ik studeer hard **zodat** ik **kan** slagen. |
| tenzij | unless | Ik kom, **tenzij** het **regent**. |

## Word Order Deep Dive

### Main Clause: Verb = Position 2
```
[Subject/Other] [VERB] [Rest] [Other verbs at end]
    Ik           heb    gisteren een boek    gelezen.
    Gisteren     heb    ik een boek          gelezen.
```

### Subordinate Clause: Verb = END
```
..., [conjunction] [subject] [rest] [VERB(s)]
..., omdat         ik        gisteren een boek   heb gelezen.
```

### Two Verbs in Subordinate Clause
When there are multiple verbs, they ALL go to the end:
- Ik denk **dat** hij morgen **kan komen**. (I think that he can come tomorrow.)
- Hij zei **dat** hij het boek **had gelezen**. (He said that he had read the book.)

## Relative Clauses (Betrekkelijke bijzinnen)

### Using **die** and **dat**
- **die** → for **de**-words and plurals
- **dat** → for **het**-words

| Example | Why die/dat? |
|---------|-------------|
| De man **die** daar staat, is mijn vader. | de man → die |
| Het boek **dat** ik lees, is interessant. | het boek → dat |
| De kinderen **die** buiten spelen... | plural → die |
| De vrouw **die** naast me woont... | de vrouw → die |

### Using **waar** (where) and **wie** (who)
- Het huis **waar** ik woon, is oud. (The house where I live is old.)
- De man **met wie** ik werk... (The man with whom I work...)

---

## Indirect Questions

The verb goes to the end (just like subordinate clauses):

| Direct Question | Indirect Question |
|----------------|-------------------|
| Waar **is** hij? | Ik weet niet waar hij **is**. |
| Wat **doe** je? | Ik vraag me af wat je **doet**. |
| Hoe laat **komt** hij? | Weet je hoe laat hij **komt**? |
| Waarom **ben** je hier? | Ik begrijp niet waarom je hier **bent**. |

## 💬 Complex Paragraph Example

> Hoewel ik pas twee jaar Nederlands leer, kan ik al best goed communiceren. Toen ik begon, vond ik het moeilijk omdat de uitspraak heel anders is dan het Engels. Maar omdat ik elke dag oefen en Nederlandse podcasts luister, is mijn niveau snel verbeterd. Ik denk dat het belangrijk is dat je niet bang bent om fouten te maken, want dat is de beste manier om te leren. Als ik klaar ben met deze cursus, wil ik het inburgeringsexamen doen, zodat ik mijn taalvaardigheid officieel kan bewijzen.
