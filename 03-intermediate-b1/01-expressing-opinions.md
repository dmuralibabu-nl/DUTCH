# 💭 Expressing Opinions

## Opinion Phrases

### Giving Your Opinion
| Dutch | English |
|-------|---------|
| Ik vind dat ... | I think that ... |
| Ik denk dat ... | I think that ... |
| Volgens mij ... | In my opinion ... |
| Naar mijn mening ... | In my opinion ... (formal) |
| Ik geloof dat ... | I believe that ... |
| Ik ben van mening dat ... | I am of the opinion that ... |
| Wat mij betreft ... | As far as I'm concerned ... |
| Als je het mij vraagt ... | If you ask me ... |

### Agreeing
| Dutch | English |
|-------|---------|
| Ik ben het met je eens | I agree with you |
| Dat klopt | That's correct |
| Precies! | Exactly! |
| Absoluut | Absolutely |
| Dat vind ik ook | I think so too |
| Je hebt gelijk | You're right |
| Daar ben ik het mee eens | I agree with that |
| Zeker weten | For sure |

### Disagreeing (Politely)
| Dutch | English |
|-------|---------|
| Ik ben het er niet mee eens | I don't agree |
| Dat zie ik anders | I see it differently |
| Dat klopt niet helemaal | That's not entirely correct |
| Daar ben ik het niet mee eens | I disagree with that |
| Ik denk het niet | I don't think so |
| Misschien, maar ... | Maybe, but ... |
| Dat is een goed punt, maar ... | That's a good point, but ... |
| Aan de andere kant ... | On the other hand ... |

## Using "vinden" (to find / to think)

**Vinden** is the main verb for expressing opinions about things:

- Ik vind het **leuk** (I think it's nice)
- Ik vind het **interessant** (I find it interesting)
- Ik vind het **saai** (I find it boring)
- Ik vind het **moeilijk** (I find it difficult)
- Ik vind het **belangrijk** (I think it's important)

**Wat vind je van ...?** = What do you think of ...?
- Wat vind je van Amsterdam? → Ik vind Amsterdam een mooie stad.
- Wat vind je van dit boek? → Ik vind het een goed boek.

---

## Subordinate Clauses with "dat" ⚠️

When you use **dat** (that), the verb goes to the **END** of the clause:

| Main clause word order | With "dat" — verb to end |
|-----------------------|--------------------------|
| Het weer **is** goed | Ik denk **dat** het weer goed **is** |
| Hij **kan** goed koken | Ik vind **dat** hij goed **kan** koken |
| Zij **heeft** hard gewerkt | Ik denk **dat** zij hard **heeft** gewerkt |

## Expressing Preferences

| Dutch | English |
|-------|---------|
| Ik hou van ... | I love ... |
| Ik hou niet van ... | I don't like ... |
| Ik heb liever ... | I prefer ... |
| Ik heb een hekel aan ... | I hate ... |
| Het maakt mij niet uit | I don't mind / It doesn't matter |
| Ik geef de voorkeur aan ... | I prefer ... (formal) |

## 💬 Sample Discussion

> **A:** Wat vind je van het Nederlandse weer?
> **B:** Ik vind het weer hier verschrikkelijk! Het regent te vaak.
> **A:** Dat klopt niet helemaal. In de zomer is het best lekker.
> **B:** Misschien, maar ik heb liever het weer in Spanje.
> **A:** Dat is waar. Maar ik vind dat Nederland veel andere voordelen heeft.
> **B:** Daar ben ik het mee eens. De fietscultuur is fantastisch!
