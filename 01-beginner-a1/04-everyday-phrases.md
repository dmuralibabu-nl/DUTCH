# 💬 Everyday Phrases

| Dutch | English | When to Use |
|-------|---------|-------------|
| Ja | Yes | — |
| Nee | No | — |
| Alstublieft | Please / Here you go | Formal |
| Alsjeblieft | Please / Here you go | Informal |

| Dankjewel | Thank you | Informal |

## Asking for Help

| Dutch | English |
|-------|---------|
| Spreekt u Engels? | Do you speak English? (formal) |
| Spreek je Engels? | Do you speak English? (informal) |
| Ik spreek een beetje Nederlands | I speak a little Dutch |
| Ik begrijp het niet | I don't understand |
| Kunt u dat herhalen? | Can you repeat that? (formal) |
| Kun je dat herhalen? | Can you repeat that? (informal) |
| Kunt u langzamer praten? | Can you speak slower? (formal) |
| Wat betekent ...? | What does ... mean? |
| Hoe zeg je ... in het Nederlands? | How do you say ... in Dutch? |
| Kunt u het opschrijven? | Can you write it down? |

## Weather Talk ☁️

| Dutch | English |
|-------|---------|
| Hoe is het weer? | How's the weather? |
| Het regent | It's raining |
| Het is zonnig | It's sunny |
| Het is koud | It's cold |
| Het is warm | It's warm |
| Het waait | It's windy |
| Het sneeuwt | It's snowing |
| Wat een lekker weertje! | What nice weather! |

> 💡 Weather is the #1 small talk topic in the Netherlands — just like in the UK!

## Common Expressions 🌟

| Dutch | Literal | Actual Meaning |
|-------|---------|---------------|
| Gezellig! | Cozy/pleasant | Wonderful atmosphere (untranslatable!) |
| Lekker | Tasty | Also: nice, pleasant, good |
| Toch? | Right/though? | Seeking confirmation |
| Nou... | Well... | Filler word |
| Zeg maar | Say but | Kind of / just say |
| Hoor | Hear | Softener (don't worry about it) |
| Even | Just/moment | Just a moment |
