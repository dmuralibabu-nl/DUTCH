# ⚔️ Debate & Argumentation

## Structuring an Argument

### Introducing Your Position
| Dutch | English |
|-------|---------|
| Ik ben van mening dat ... | I am of the opinion that ... |
| Mijn standpunt is dat ... | My position is that ... |
| Ik wil betogen dat ... | I want to argue that ... |
| Laten we beginnen met ... | Let's start with ... |
| De kern van het probleem is ... | The core of the problem is ... |
| Het is algemeen bekend dat ... | It is widely known that ... |

### Supporting Your Argument
| Dutch | English |
|-------|---------|
| Ten eerste ... ten tweede ... | Firstly ... secondly ... |
| Bovendien ... | Moreover ... |
| Daar komt bij dat ... | In addition to that ... |
| Dit wordt bevestigd door ... | This is confirmed by ... |
| Uit onderzoek blijkt dat ... | Research shows that ... |
| Een goed voorbeeld hiervan is ... | A good example of this is ... |
| Het is belangrijk om te benadrukken dat ... | It's important to emphasize that ... |
| Dit betekent in de praktijk dat ... | In practice, this means that ... |

### Presenting Counter-Arguments
| Dutch | English |
|-------|---------|
| Aan de andere kant ... | On the other hand ... |
| Tegenstanders beweren dat ... | Opponents claim that ... |
| Men zou kunnen zeggen dat ... | One could say that ... |
| Hoewel dit waar is, ... | Although this is true, ... |
| Dit argument gaat echter niet op, want ... | This argument doesn't hold, because ... |
| Ondanks dit bezwaar ... | Despite this objection ... |
| Het tegendeel is echter waar | The opposite is true, however |

### Concluding
| Dutch | English |
|-------|---------|
| Samenvattend ... | In summary ... |
| Kortom ... | In short ... |
| Alles overwegend ... | All things considered ... |
| Op grond van het bovenstaande ... | Based on the above ... |
| Ik concludeer dat ... | I conclude that ... |
| Het staat vast dat ... | It is certain that ... |
| De conclusie is dan ook dat ... | The conclusion therefore is that ... |

## Debating Techniques

### Asking Critical Questions
| Dutch | English |
|-------|---------|
| Kunt u dat onderbouwen? | Can you substantiate that? |
| Waar baseert u dat op? | What do you base that on? |
| Is dat niet een beetje kort door de bocht? | Isn't that a bit simplistic? |
| Heeft u daar bewijs voor? | Do you have evidence for that? |
| Hoe verklaart u dan dat ...? | How do you then explain that ...? |

### Expressing Certainty / Uncertainty
| Dutch | Level |
|-------|-------|
| Het staat vast dat ... | Certain |
| Het is duidelijk dat ... | Clear |
| Waarschijnlijk ... | Probably |
| Misschien ... | Maybe |
| Het zou kunnen dat ... | It could be that ... |
| Het is onwaarschijnlijk dat ... | It's unlikely that ... |
| Ik betwijfel of ... | I doubt whether ... |

## 💬 Sample Debate: "Should the Netherlands Switch to English?"

### For (Voor):
> Ik ben van mening dat Nederland meer Engels zou moeten gebruiken. Ten eerste is Engels de internationale taal van wetenschap en business. Bovendien spreken de meeste Nederlanders al uitstekend Engels. Dit zou het land aantrekkelijker maken voor internationale bedrijven en talent.

### Against (Tegen):
> Ik ben het hier niet mee eens. Het Nederlands is een belangrijk onderdeel van onze culturele identiteit. Hoewel het waar is dat veel Nederlanders goed Engels spreken, betekent dat niet dat we onze eigen taal moeten opgeven. Uit onderzoek blijkt dat meertaligheid juist goed is voor de economie. Bovendien hebben we een verantwoordelijkheid om het Nederlands te beschermen voor toekomstige generaties.

## Writing an Essay (Betoog)

### Structure
1. **Inleiding** (Introduction) — present the topic and your thesis
2. **Argumenten** (Arguments) — 2-3 arguments with examples
3. **Tegenargument** (Counter-argument) — address the other side
4. **Conclusie** (Conclusion) — summarize and restate your position

### Linking Words Summary
| Function | Dutch Options |
|----------|-------------|
| Adding | en, ook, bovendien, daarnaast, verder |
| Contrasting | maar, echter, toch, desondanks, hoewel |
| Cause | want, omdat, doordat, namelijk, immers |
| Result | dus, daarom, daardoor, hierdoor, zodat |
| Time | toen, terwijl, nadat, voordat, totdat |
| Summarizing | kortom, samenvattend, al met al |
